# Preservation policy

This repository is a documentation and organization layer around the original work.

## Preserved without modification

The following artifact types were copied byte-for-byte:

- LTspice `.asc` circuit files
- Submitted PDF reports
- Simulation screenshots

No original circuit was refactored, corrected, reformatted, re-saved, or regenerated.

## Changes limited to repository organization

- Original files were placed into descriptive project folders.
- Submission PDFs were renamed to `submission.pdf` at the filesystem level so the public GitHub path does not expose the student number. Their binary contents are unchanged.
- New README and verification files were added.
- Preview PNG files in `assets/` were rendered from selected pages of the original reports; they are derivatives for navigation and do not replace the original PDFs.

## Exclusions

Peer submissions, assignment sheets, tutorials, duplicate files, macOS metadata, and other non-author portfolio material were not included. See `docs/EXCLUDED_FILES.md`.
